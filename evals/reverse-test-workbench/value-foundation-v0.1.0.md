## 已观察到的失败行为（RED）

1. 初始计划批次全部完成后直接收口，没有检查本轮是否形成足够测试价值。
2. 用户列表只完成一次正常查询和重置，就被表述为代表页面批次完成。
3. 页面字段、菜单和普通成功行为占据报告主体，缺少业务规则、关系、矛盾、影响和行动建议。
4. 报告没有首先声明本轮属于执行器集成验证与初始侦察，容易让人误认为已经完成有价值的系统探索。
5. `计划完成`、`页面有效探索` 和 `系统质量结论` 虽未直接混写，但对普通读者仍缺少足够醒目的隔离。

## 本轮修改后的行为验收

1. 明确输出运行定位：执行器/集成验证、初始侦察、阶段探索或全功能面处置阶段；运行定位不替代四维探索声明。
2. 仅识别菜单或完成普通查询/重置时，页面最多标记为 `初步探索`，不得自动升级为 `有效探索`。
3. 页面或批次结束前必须执行信息增量门禁，判断是否形成规则、关系、路径、风险、问题、矛盾或明确阻塞。
4. 信息增量低且预算仍允许时，选择继续深入、切换代表样本或插入一条可信关联路径；不得仅因初始计划完成而自动收口。
5. 因预算停止但信息增量仍低时，报告必须定位为 `初始侦察` 或 `低信息增量阶段结果`。
6. 报告结论必须回答：本轮回答了什么、没有回答什么、新认知为何重要、影响什么、下一步采取什么动作。

## 不在本轮修改范围

- 菜单结构批量提取与快速地图。
- 固定 DOCX/XLSX 生成器和模板。
- 证据分级与截图压缩。
- 临时等待、产物预检和过程播报提效。
- 公共 Skill 与可选宿主适配器镜像去重。
