# 宿主集成能力契约

这是跨 Agent、跨操作系统的最小能力契约。Skill 不假设宿主名称、安装目录、Shell、包管理器或浏览器 profile。

## 必需能力

宿主至少需要能够：

1. 加载 `SKILL.md` 和按需读取 `references/`、`scripts/`、`assets/`。
2. 暴露官方 Playwright MCP 或与其等价的宿主适配器。
3. 创建或控制一个受控页面，并完成导航、结构化页面观察、点击、输入、截图和页面状态读取。
4. 把当前页面实际状态、工具错误和动作结果返回给 Agent。

## 推荐能力

- `browser_navigate`
- `browser_snapshot`
- `browser_click`
- `browser_type` 或等价输入能力
- `browser_take_screenshot`
- 页面标题、URL、可见文本或可访问性结构读取

宿主可以使用不同的工具命名、MCP 传输和浏览器通道，但必须在能力门禁中映射到上述语义。不能映射的能力必须记录为不可用，不得假装成功。

## 可选能力

- 多模态视觉：补充布局、图表、Canvas、遮挡、颜色和响应式判断。
- 文档/表格运行时：生成 DOCX/XLSX；不可用时保留 JSON/evidence。
- 页面会话继承：只有明确验证成功时才继承既有登录态，否则从登录页开始。
- 被动网络/控制台观察：只能作为辅助证据，不替代 UI 路径。

## 适配器责任

宿主适配器可以负责 MCP 的安装、版本锁定、浏览器依赖、权限申请和运行时配置，但必须：

- 使用官方 Playwright MCP 或明确声明不满足本 Skill 的首选执行协议。
- 向 Skill 暴露实际版本、浏览器通道、传输方式和能力状态。
- 失败时提供一个最小、可执行的恢复动作。
- 不改变 Skill 的风险分级、覆盖承诺、调度、证据和结论边界。

完全不支持 Skill 指令、MCP 或等价浏览器控制的普通聊天产品，不在本 Skill 的可执行范围内。
